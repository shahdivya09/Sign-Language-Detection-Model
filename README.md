# Sign Language Detection Model 🤟

This project implements a real-time **Sign Language Detection System** using **OpenCV**, **MediaPipe**, and a deep learning model built with **TensorFlow/Keras**. It captures hand gestures through a webcam and classifies them into sign language actions.

---

## 🚀 Features

- Real-time video capture using OpenCV
- Hand landmark detection with MediaPipe
- Keypoint extraction for model input
- LSTM-based deep learning model for gesture classification
- Live visualization of predictions on the video feed
